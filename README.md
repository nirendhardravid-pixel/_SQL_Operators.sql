## SQL Operators

This section covers SQL operators used to perform calculations, compare values, and filter data.

### Topics Covered

* **Arithmetic Operators:** `+`, `-`, `*`, `/`, `%`
* **Comparison Operators:** `=`, `<>`, `!=`, `>`, `<`, `>=`, `<=`
* **Logical Operators:** `AND`, `OR`, `NOT`
* **Special Operators:** `IN`, `BETWEEN`, `LIKE`, `IS NULL`
* **Other Operators:** `EXISTS`, `ANY`, `ALL`

### Objective

To understand and practice SQL operators for effective data filtering, comparison, and analysis.
